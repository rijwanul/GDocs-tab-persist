If it's not working

  1. Open the Google Doc, then open DevTools (F12) → Console tab.
  2. Edit content.js in the unpacked extension folder and set DEBUG = true near the top, then reload the extension in chrome://extensions and refresh the doc.
  3. Watch the console for lines starting with [TabPersist]. If you see "No tab tree found yet" repeatedly, Google has likely changed the tab tree's ARIA markup.
  4. In DevTools, run document.querySelectorAll('[role="treeitem"]').length and document.querySelectorAll('.chapterItemArrowContainer[role="button"]').length. If either returns 0, Google has changed the tab sidebar's markup — copy those results and the console output back to Claude to get an updated content.js.

Known limitation

Google Docs briefly renders all tabs expanded before this extension can react and correct it, so you may see a short flash on load before it settles into your saved layout. This is a limitation of any content-script-based fix — there's no Docs setting to disable the default-expanded behavior.
